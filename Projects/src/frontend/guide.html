Tubify 이용 가이드

설치부터 뉴스레터 수신까지, Tubify를 100% 활용하는 방법을 안내드립니다.

STEP 01 시작하기 로그인 및 익스텐션 설치 STEP 02 실시간 분석 AI 사이드패널 사용법 STEP 03 관심 토픽 등록 하트로 뉴스레터 구독 STEP 04 뉴스레터 설정 발송 시간 및 구독 관리
1
시작하기
Google 로그인 후 크롬 익스텐션을 설치하면 모든 준비가 완료됩니다.
🔐
STEP 1
Google 계정으로 로그인
Tubify는 별도의 회원가입 없이 Google 계정으로 바로 시작할 수 있습니다. 홈 화면의 로그인 버튼을 클릭하면 구글 인증 페이지로 이동합니다.
수집 정보: 이름, 이메일, 프로필 이미지만 수집합니다. YouTube 시청 기록이나 구독 정보에는 접근하지 않습니다.
🧩
STEP 2
크롬 익스텐션 설치
로그인 후 Chrome 웹 스토어로 이동해 Tubify 익스텐션을 설치합니다. Chrome에 추가 버튼을 클릭하고 권한을 허용해주세요.
필요 권한:
· 활성 탭 읽기 — 현재 보고 있는 YouTube 페이지 정보 감지
· 사이드 패널 — 화면 오른쪽에 분석 패널 표시
· 저장소 — 로그인 토큰 및 설정 저장
Chrome 웹 스토어에서 설치
✅
STEP 3
설치 확인 및 로그인 연동
설치 완료 후 YouTube에 접속하면 화면 우측 하단에 빨간 말풍선 버튼이 나타납니다. 버튼이 보이면 모든 준비가 된 것입니다.
버튼이 안 보인다면? 페이지를 새로고침(F5)하거나, 크롬 우측 상단 퍼즐 아이콘 → Tubify를 클릭해 익스텐션이 활성화됐는지 확인해주세요.
2
실시간 AI 분석
YouTube에서 검색하거나 영상을 볼 때, 빨간 버튼 하나로 AI 분석 결과를 바로 확인하세요.
1
YouTube에서 검색하거나 영상을 재생하세요
검색 결과 페이지 또는 영상 시청 페이지 어디서든 사용할 수 있습니다. Tubify가 현재 보고 있는 키워드나 영상 제목을 자동으로 감지합니다.
2
화면 우측 하단의 빨간 말풍선 버튼을 클릭하세요
클릭하면 화면 오른쪽에 Tubify 사이드패널이 열립니다. 관련 영상들을 자동으로 수집하고 AI 분석을 시작합니다.
3
3단계 로딩 후 결과를 확인하세요
① 의도 분류 → ② 영상 선정 → ③ 자막 분석 순서로 진행됩니다. 보통 10~20초 내에 완료됩니다.
광고 탐지
자막·설명란·API 플래그 4계층으로 광고 여부를 0~100점으로 표시합니다. 협찬·유료광고 영상을 자동으로 구분해드립니다.
신뢰도 점수
87 / 100
예시 수치
채널 구독자 수, 자막 품질, 정보 일관성 등을 종합해 산출
핵심 요약
관련 영상 5개의 자막을 교차 분석해 공통으로 언급된 사실과 영상 간 의견 차이(쟁점)를 분리해서 보여줍니다.
의도별 레이아웃
검색 의도를 자동 판별해 화면 구성을 다르게 보여줍니다.
· 유희형 — 영상 카드 우선 노출
· 지식형 — 요약 + 공통사실/쟁점
· 구매형 — 장단점 비교 패널
3
관심 토픽 등록 (하트 ♥)
마음에 드는 주제에 하트를 누르면, 그 토픽으로 뉴스레터를 발송해드립니다.
♥
사이드패널에서 하트 누르기
분석 결과 상단의 하트 버튼을 클릭하면 해당 토픽이 관심 목록에 추가됩니다. 다시 누르면 취소됩니다.
최대 5개 등록 가능
📋
마이페이지에서 관리
등록한 관심 토픽 목록을 마이페이지에서 확인하고 삭제할 수 있습니다. 토픽당 분석된 영상 수도 함께 표시됩니다.
관심 토픽 관리
📧
자동 뉴스레터 발송
등록된 관심 토픽을 기반으로 매일 설정한 시간에 AI가 분석한 뉴스레터를 이메일로 보내드립니다.
등록 즉시 적용
1
분석 결과 확인 후 하트 버튼 클릭
사이드패널 상단 또는 요약 카드 옆의 ♥ 버튼을 클릭하세요. "○○○ 관련 뉴스레터를 보내드릴게요! 💌" 토스트 메시지가 뜨면 등록 완료입니다.
2
관심 토픽은 최대 5개까지
5개를 초과하면 "관심 토픽은 최대 5개까지 저장할 수 있어요." 안내가 나타납니다. 마이페이지에서 기존 토픽을 삭제한 후 새로 추가할 수 있습니다.
3
뉴스레터 구독 취소도 하트로
이미 하트를 누른 토픽에서 다시 하트를 클릭하면 관심 취소와 함께 뉴스레터 수신이 중단됩니다. 마이페이지의 이메일 구독 취소 링크를 통해서도 개별 토픽을 취소할 수 있습니다.
4
뉴스레터 설정
발송 시간을 설정하고 매일 AI가 큐레이션한 유튜브 브리핑을 받아보세요.
⏰
발송 시간 설정
마이페이지 → 발송 시간 설정에서 원하는 시간을 입력하세요. 매일 해당 시간에 맞춰 자동으로 발송됩니다.
24시간 형식 HH:MM
🧠
의도 맞춤 뉴스레터
등록한 토픽의 특성을 AI가 분석해 유희형·지식형·구매형에 맞는 형식과 말투로 내용을 구성합니다.
AI 자동 판별
📬
발송 이력 확인
마이페이지 → 뉴스레터 히스토리에서 지금까지 받은 뉴스레터 내용을 모두 다시 확인할 수 있습니다.
발송 이력 보관
🚫
수신 거부
뉴스레터 하단의 수신 거부 링크를 클릭하거나, 마이페이지에서 전체 구독을 취소할 수 있습니다. 언제든지 다시 구독할 수 있습니다.
즉시 적용

· 등록된 관심 토픽이 0개인 경우 해당 회차 발송이 skip됩니다.
· 설정한 시간과 서버 시간이 일치해야 합니다 (한국 표준시 KST 기준).
· 스팸 또는 프로모션 폴더를 확인해주세요.

자주 묻는 질문
사용 중 궁금한 점을 확인해보세요.
YouTube 외 다른 사이트에서도 사용할 수 있나요? ▾
현재 Tubify 익스텐션은 YouTube(youtube.com)에서만 동작합니다. 검색 결과 페이지와 영상 시청 페이지 모두 지원합니다.
분석 결과가 나오는 데 얼마나 걸리나요? ▾
일반적으로 10~20초 내외입니다. 관련 영상 5개의 자막을 병렬로 분석하기 때문에 서버 상태나 영상 길이에 따라 다소 차이가 있을 수 있습니다.
자막이 없는 영상은 어떻게 처리되나요? ▾
자막이 없는 영상은 AI 분석 없이 규칙 기반 광고 탐지만 수행됩니다. 요약과 교차 분석은 자막이 있는 영상들로만 구성됩니다.
관심 토픽을 등록했는데 뉴스레터가 오지 않아요. ▾
마이페이지에서 이메일 주소와 발송 시간이 올바르게 설정됐는지 확인해주세요. 발송 시간 설정이 없으면 뉴스레터가 발송되지 않습니다. 스팸·프로모션 폴더도 확인해보세요.
내 유튜브 시청 기록이 수집되나요? ▾
아니요. Tubify는 사용자가 직접 검색하거나 시청 중인 페이지의 키워드만 사용하며, YouTube 시청 기록·구독 정보·계정 데이터에는 일절 접근하지 않습니다. 수집 정보는 이름·이메일·프로필 이미지가 전부입니다.
로그인이 되지 않거나 버튼이 보이지 않아요. ▾
① YouTube 페이지를 새로고침(F5)해보세요.
② 크롬 우측 상단 퍼즐 아이콘에서 Tubify가 활성화되어 있는지 확인하세요.
③ 익스텐션을 삭제 후 재설치해보세요.
④ 위 방법으로도 해결이 안 되면 tutubifyswproject@gmail.com으로 문의해주세요.
