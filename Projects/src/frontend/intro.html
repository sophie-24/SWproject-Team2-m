HOW IT WORKS

3단계로 끝납니다

설치부터 분석 결과 확인까지, 복잡한 설정 없이 바로 사용할 수 있습니다.

01
익스텐션 설치

Chrome에 Tubify 익스텐션을 추가하고 계정을 연결합니다.

02
YouTube에서 영상 시청

평소처럼 유튜브를 열면 화면 옆에 플로팅 버튼이 나타납니다.

03
버튼 클릭 → 분석 시작

한 번의 클릭으로 영상 요약, 핵심 주장, 신뢰도 평가를 즉시 확인합니다.

INSTALL GUIDE

지금 바로 설치하세요

Chrome 브라우저에서 4단계로 Tubify를 설치할 수 있습니다.

01
Chrome 웹스토어에서 설치

아래 버튼을 눌러 Chrome 웹스토어에서 Tubify 익스텐션을 설치합니다.

Chrome Web Store →
02
회원가입

Tubify 사이트에서 Google 계정으로 간편하게 회원가입합니다. 별도의 비밀번호 설정이 필요 없습니다.

Google 소셜 로그인
03
YouTube 열기

YouTube에 접속하면 화면 옆에 Tubify 플로팅 버튼이 자동으로 나타납니다.

자동 활성화
04
버튼 클릭 → 분석 시작

영상을 보다가 플로팅 버튼을 누르면 AI 분석이 즉시 시작됩니다. 설정은 필요 없습니다.
