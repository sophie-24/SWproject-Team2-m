HOW IT WORKS

3단계로 끝납니다

설치부터 분석 결과 확인까지, 복잡한 설정 없이 바로 사용할 수 있습니다.

01
익스텐션 설치

Chrome에 Tubify 익스텐션을 추가하고 계정을 연결합니다.

02
YouTube에서 영상 시청

평소처럼 유튜브를 열면 화면 옆에 플로팅 버튼이 나타납니다.

03
버튼 클릭 → 분석 시작

한 번의 클릭으로 영상 요약, 핵심 주장, 신뢰도 평가를 즉시 확인합니다.

INTELLIGENT EXTENSION

영상을 보는 동시에
핵심을 짚어냅니다

AI가 자막을 분석해 3가지 관점으로 영상을 해석합니다.
단순 요약을 넘어, 신뢰도와 광고 여부까지 한눈에 확인하세요.

SUMMARY
영상 요약 & 신뢰도

현재 보고 있는 영상의 핵심 내용, 주요 주장, 신뢰도 점수를 즉시 요약합니다. 광고 포함 여부도 자동으로 감지합니다.

INSIGHTS
토픽 심층 분석

같은 주제를 다룬 영상 5개를 교차 분석해 공통 사실, 논쟁점, 주요 인사이트를 정리합니다.

SOURCES
출처 영상 확인

분석에 사용된 관련 영상 5개의 링크, 채널, 광고 여부를 한 곳에서 확인하고 바로 이동할 수 있습니다.

SNAP SUMMARY

한 편의 영상,
몇 줄의 핵심으로.

영상 전체를 볼 시간이 없다면, 핵심만 확인하세요.
유튜브 자막을 AI가 분석해 주요 내용과 인사이트를 즉시 정리합니다.
광고 포함 여부와 신뢰도 점수도 함께 제공됩니다.

DAILY MAIL

관심 주제를 담아
원하는 시간에 메일함으로

유튜브 시청 중 저장한 관심 토픽을 기반으로
AI가 최신 영상들을 분석해 핵심 인사이트만 골라 메일로 보내드립니다.
구독을 원하지 않는 토픽은 메일에서 바로 해제할 수 있습니다.

Chrome 웹스토어에서 Tubify를 검색하거나 아래 버튼을 눌러 익스텐션을 설치합니다.

Chrome Web Store
02
회원가입

Tubify 사이트에서 Google 계정으로 간편하게 회원가입합니다. 별도의 비밀번호 설정이 필요 없습니다.

Google 소셜 로그인
03
YouTube 열기

자동 활성화

영상을 보다가 플로팅 버튼을 누르면 AI 분석이 즉시 시작됩니다. 설정은 필요 없습니다.
